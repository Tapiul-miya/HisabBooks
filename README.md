# Hisab Book - হিসাব খাতা (Android & Web)

হিসাব খাতা প্রজেক্টে আপনাকে স্বাগতম! এই ডক ফাইলটিতে অ্যাপটির অ্যান্ড্রয়েড APK বিল্ড করার নিয়ম, পারমিশন এবং গুগল সাইন-ইন সচল করার সহজ নির্দেশনাবলী বাংলায় দেওয়া হলো।

---

## 📱 ১. অ্যান্ড্রয়েড APK বিল্ড করার নিয়ম (How to Build Android APK)

এই অ্যাপটি **React + Vite** এবং **Capacitor** ফ্রেমওয়ার্ক দিয়ে তৈরি করা হয়েছে। আপনি দুইভাবে এটি বিল্ড করতে পারেন:

### ক. গিটহাব অ্যাকশনের মাধ্যমে স্বয়ংক্রিয় বিল্ড (GitHub Actions - Automatic Build)
আপনার প্রজেক্টের প্রতিটি পুশ বা পুল রিকোয়েস্টে GitHub Actions স্বয়ংক্রিয়ভাবে একটি নতুন ফ্রেশ Debug APK বিল্ড করে।
1. আপনার গিটহাব রিপোজিটরির **Actions** ট্যাবে যান।
2. **Build Android APK** ওয়ার্কফ্লোটি সিলেক্ট করুন।
3. সর্বশেষ বিল্ড সফল হলে নিচে স্ক্রোল করে **Artifacts** সেকশন থেকে `HisabBook-Debug-APK` জিপ ফাইলটি ডাউনলোড করে নিন।

### খ. লোকাল কম্পিউটারে বিল্ড করার নিয়ম (Manual Local Build)
লোকাল কম্পিউটারে বিল্ড করার জন্য নিচের রিকোয়ারমেন্টগুলো থাকা লাগবে:
* **Node.js** (v20+)
* **Java JDK** 21
* **Android Studio** এবং Android SDK

**ধাপসমূহ:**
1. প্রথমে ডিপেন্ডেন্সি ইনস্টল করুন:
   ```bash
   npm install --legacy-peer-deps
   ```
2. প্রজেক্টের প্রোডাকশন ওয়েব বিল্ড তৈরি করুন:
   ```bash
   npm run build
   ```
3. ক্যাপিজিটর সিঙ্ক করুন যাতে ওয়েব কোড অ্যান্ড্রয়েডে ট্রান্সফার হয়:
   ```bash
   npx cap sync android
   ```
4. অ্যান্ড্রয়েড ডিরেক্টরিতে গিয়ে গ্র্যাডল কমান্ডের মাধ্যমে APK কম্পাইল করুন:
   ```bash
   cd android
   ./gradlew assembleDebug
   ```
   *বিল্ড শেষে আপনার APK ফাইলটি পাবেন এই পাথে:* `android/app/build/outputs/apk/debug/app-debug.apk`

## 🔒 ২. অ্যাপের অনুমতিসমূহ (Permissions Granted)

অ্যাপ্লিকেশনটিতে গুগল ড্রাইভ ব্যাকআপ, রিস্টোর এবং অফলাইন ডাটাবেস পরিচালনার জন্য শুধুমাত্র প্রয়োজনীয় পারমিশনগুলো দেওয়া আছে। `android/app/src/main/AndroidManifest.xml` ফাইলে নিচের পারমিশনগুলো ডিক্লেয়ার করা আছে:

1. **ইন্টারনেট পারমিশন (`android.permission.INTERNET`):**
   * গুগল ড্রাইভ ক্লাউডে হিসাব ডাটা ব্যাকআপ এবং ওঅথ (OAuth) সাইন-ইন করার জন্য।
2. **নেটওয়ার্ক স্টেট পারমিশন (`android.permission.ACCESS_NETWORK_STATE`):**
   * ইন্টারনেট সংযোগ আছে কি না তা যাচাই করে অফলাইন মোড সক্রিয় রাখার জন্য।

## 🔑 ৩. গুগল অটো সাইন-ইন সচল করার সহজ নিয়ম (Steps for Google Auto Sign-In)

অ্যান্ড্রয়েড অ্যাপে গুগল সাইন-ইনের সিকিউরিটি কঠোরভাবে সংরক্ষিত থাকে। এটি সচল করতে নিচের ৩টি সহজ ধাপ সম্পন্ন করতে হবে:

### ধাপ ১: আপনার APK-এর SHA-1 কি বের করুন (Get SHA-1 Fingerprint)
* **GitHub Actions থেকে:**
  আপনার গিটহাবের সাকসেসফুল বিল্ড রানটিতে ক্লিক করে **Build Android Debug APK** জবের রান টাইম লগে যান। সেখানে `=== SHA-1 FINGERPRINT FOR GOOGLE CONSOLE ===` সেকশনে আপনার ইউনিক SHA-1 কী-টি দেখতে পাবেন। সেটি কপি করুন।
* **লোকাল মেশিন থেকে:**
  টার্মিনালে বা কমান্ড প্রম্পটে আপনার অ্যান্ড্রয়েড ডিরেক্টরিতে গিয়ে নিচের কমান্ডটি রান করুন:
  ```bash
  keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android
  ```

### ধাপ ২: ফায়ারবেস/গুগল কনসোলে যুক্ত করা (Add SHA-1 to Firebase Console)
1. আপনার [Firebase Console](https://console.firebase.google.com/)-এ যান।
2. **Project Settings** (গিয়ার আইকন) > **General** ট্যাবে প্রবেশ করুন।
3. নিচে আপনার অ্যান্ড্রয়েড অ্যাপটি (`com.hisabbook.app`) সিলেক্ট করুন।
4. **Add fingerprint** বাটনে ক্লিক করে কপি করা **SHA-1** ফিঙ্গারপ্রিন্ট কি-টি পেস্ট করে সেভ করুন।

### ধাপ ৩: ক্যাপিজিটর কনফিগারেশনে ক্লায়েন্ট আইডি ম্যাপিং
আমরা অলরেডি আপনার কনফিগারেশন ফাইলে ক্লায়েন্ট আইডিগুলো প্রপারলি ম্যাপ করে দিয়েছি।

* **Web Client ID (Server Exchange):** `13178099429-u613g9lmhp7vjf7saut3ov1brhftdbm9.apps.googleusercontent.com`

*সবকিছু সঠিকভাবে কনফিগার করা থাকলে অ্যাপ ওপেন করার পর গুগল ওঅথ বাটনটিতে ক্লিক করলেই প্লে সার্ভিসেস অ্যাকাউন্ট পিকার চলে আসবে এবং অটোমেটিক ব্যাকআপ তালিকা দেখতে পাবেন।*

## 📁 ৪. ডাটা সুরক্ষায় লোকাল অফলাইন ব্যাকআপ (Manual Offline Backup)

গুগল সাইন-ইন ছাড়াও ডাটার সর্বোচ্চ সুরক্ষায় অ্যাপটিতে একটি অফলাইন ম্যানুয়াল ব্যাকআপ মেকানিজম রয়েছে:
* **সেটিংস > ব্যাকআপ ও রিস্টোর** সেকশনে যান।
* **ডাউনলোড ব্যাকআপ ফাইল (JSON / CSV)** বাটনে ক্লিক করুন।
* ফাইলটি আপনার মোবাইলের মেমরিতে ডাউনলোড হয়ে থাকবে। পরবর্তীতে যেকোনো সময়ে যেকোনো ডিভাইসে অ্যাপ ওপেন করে এই ফাইলটি আপলোড করলেই সাথে সাথে আপনার সমস্ত হিসাব রিস্টোর হয়ে যাবে।
